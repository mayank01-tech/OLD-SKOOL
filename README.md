# 🏋️ Old Skool Gym

**A classic gym website built with HTML, CSS & JavaScript.**

Old Skool Gym is a frontend web development project designed to showcase a gym's identity, fitness environment, and overall online presence. The website focuses on a clean layout, attractive visuals, and a responsive user experience.

## ✨ Features

- Clean and modern gym website design.
- Attractive fitness-related images.
- Responsive navigation layout.
- Interactive hamburger menu for mobile navigation.
- Simple and user-friendly interface.
- Structured sections to showcase the gym.

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and layouts |
| JavaScript | Basic hamburger menu functionality |

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Run `index.html` in your browser.

That's it! No additional dependencies or installations required.
